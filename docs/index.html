What this map is

A pilot joining socalfishreports.com dock totals (kept fish, anglers, species, trip type) with free NOAA Marine Cadastre AIS for LA-basin sportfishing boats. AIS tells us where matched vessels hung offshore; dock totals tell us what was kept that day. Nothing here invents MMSIs or catch counts.

Processing pipeline

  1. scrape_fish_reports.py — yearly trip shards under data/raw/fish_reports/by_year/
  2. extract_ais.py — Cadastre days → fleet-filtered parquet in data/processed/ais_daily/
  3. detect_stops.py — low-SOG offshore dwells outside home-dock exclusion radii
  4. build_map_data.py — cluster stops into spots, join dock totals, dwell-share attribution → docs/data/
  5. build_courses_data.py — schematic home→stops→home courses → courses.json

Offshore stops & spot clustering

Stop detection

  • Speed over ground ≤ 0.8 kn
  • Duration ≥ 10 minutes
  • Outside configured home-dock radii (harbor loitering excluded)
  • Short AIS gaps (≤ ~8 min) may merge within a stop; longer gaps start a new stop
  • Stop dates use America/Los_Angeles; overnight trips also pull prior local days when joining

Feature / spot clustering

Stops within 150 ft (45.72 m) of a shared centroid are the same “spot” (AIS/GPS revisit scatter). Clustering is centroid-bounded so points don’t chain along a reef into one mega-feature.

Math & metrics

Trip-level (dock totals)

fish/person (FPP) = total kept fish ÷ anglers
fish/person/hour (trip FPH) = FPP ÷ nominal trip hours

Nominal hours from trip_type (dock totals have no clock times):

ProductHours used
½ day≈ 5 h
¾ day≈ 8 h
Full day≈ 11 h
Overnight≈ 18 h
N-day≈ N × 12 h

Trip FPP/FPH are whole-trip rates — they are not split across stops by themselves.

Dwell share (how catch is split across spots)

dwell_share = spot_dwell ÷ total_offshore_dwell on that trip
attributed fish = trip kept fish × dwell_share
attributed angler-hours = anglers × nominal_trip_hours × dwell_share
dwell-attributed FPH = Σ attributed fish ÷ Σ attributed angler-hours

Only trips with matched offshore AIS stops get this split. Trips with no species breakdown are labeled Unknown fish in the species filter.

Mean dwell share (sort)

Average of per-visit dwell_share at a spot. High values mean boats spent a large fraction of that trip’s offshore time here.

UI filters & sorting

  • Date range — dual slider on Spots (All days), Courses, and Heatmap; re-aggregates visits inside the window
  • One day (Spots) — loads that day’s join file only
  • Boat — multi-select (⌘/Ctrl+click); empty = all; keep visits/courses for any selected vessel
  • Species — multi-select individuals or groups (by type: Rockfish, Bass…; by habitat: Bottom / Kelp / Surface…). Empty = all; match any. Edit groups via the Groups button (browser localStorage + JSON export)
  • Sort spots — dwell-attributed FPH, mean dwell share, species fish count, trip FPH/FPP, total dwell, boat-days
  • Reset — clears filters/controls and returns to Spots / All days

Map tabs

  • Spots — circle markers; size ∝ dwell; color ∝ dwell-attributed FPH
  • Courses — schematic polylines home → stops (time order) → home (not raw AIS tracks). Up to 2,500 paths drawn per filter for performance
  • Heatmap — density of the same clustered spots; intensity = dwell, boat-days, attributed fish, dwell FPH, or trip FPP. Color scale auto-rescales to the current boat/species/date filter. Default kernel is the minimum (4 px radius / 3 px blur)

Known limits

  • Many LA charters still lack a reliable AIS MMSI match — those trips never get offshore stops (help match MMSIs)
  • No Marine Cadastre csv2026 yet; 2026 YTD has dock totals but little/no Cadastre AIS
  • Dock totals are trip-level; dwell share is an attribution model, not a claim that every fish was caught on that pin
  • Nominal hours are schedule approximations, not measured trip clocks
  • aisstream live capture only fills forward while a collector is running

Pipeline details and feedback live in FEEDBACK.md in the repo. Config thresholds: scripts/config.py, trip hours: scripts/trip_duration.py, attribution: scripts/catch_attribution.py.
